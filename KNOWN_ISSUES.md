# Известные проблемы KSPI-E

Список, чтобы знать, где может подвести. Источники:
1. **Найдено у нас** — в игре со сборкой Kerbalism 3.43 + JNSQ + IFS 3.30 + CryoTanks + BDB (проект ClaudeKSP).
2. **Открытые сообщения об ошибках** у автора: https://github.com/sswelm/KSP-Interstellar-Extended/issues (выгружено 2026-10-31, 58 открытых).

Статусы: **есть** — проблема в коде/конфигах этого форка; **исправлено в форке**; **исправлено у автора** (в master, не в выпуске 1.29.6); **не проверено**; **не наше** — касается мода, которого в нашей сборке нет.

| [#696](https://github.com/sswelm/KSP-Interstellar-Extended/issues/696) | «Swap fuel» у реактора навсегда удаляет используемое топливо. | исправлено в форке (2026-11-02, `InterstellarFissionMSRGC.cs`). Причина: ёмкость баков нового топлива считалась от «главного топлива» режима, в котором реактор загрузился, а если в этом режиме кончилось хоть одно топливо (обычный повод для смены), настройка пропускалась и плотность оставалась 0 → после смены у реактора все баки топлива 0/0, заправить его больше нельзя ни сейчас, ни после загрузки (воспроизведено через MCP на `Scaut`, ЯРРС: бридинг → загрузка → «Uranium» = U-233 0/0). Теперь смена сохраняет **массу** топливной загрузки активной зоны; смена не делается (с сообщением), если топливо некуда слить или в реакторе актиниды; реактор, уже сломанный старой сменой, при загрузке получает ёмкость обратно. Проверено в игре: ЯРРС Uranium → Thorium (408) → бридинг (Be 32,4 / Th 265,1 / U-233 84,5) → загрузка → Uranium 250/250, весь U-233 корабля на месте; оба отказа с сообщением |
| [#678](https://github.com/sswelm/KSP-Interstellar-Extended/issues/678) | При смене топлива у реактора на жидком металле и солевого реактора пропадают баки (EnrU, бериллий). | исправлено в форке (2026-11-02), та же причина, что у #696: у ТЭЯР режим по умолчанию «Uranium-238 TWR», его главного топлива (обеднённый уран) в детали нет → плотность эталона 0 → после смены бак EnrU 0/0 навсегда. Попутно (ревью): у KANDL режим по умолчанию тоже без его топлива (Pu-238) — при загрузке реактор переходит в режим, под который у детали есть баки; у KANDL, KANDL2, LightBulb3, LiquidCoreEngine2 нет ресурса актинидов, и кнопка смены в выходе у них по-прежнему молча ничего не делает (так у автора) |
